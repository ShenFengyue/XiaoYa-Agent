# XiaoYa

一个用于演示心理学自我觉察对话的 agent demo。

它会帮助用户：
- 识别潜在的心理创伤线索
- 理解回避、讨好、理性化、控制等防御性行为
- 通过温和提问和小练习推进自我反思

运行前请配置：
- `DEEPSEEK_API_KEY`
- 可选：`DEEPSEEK_BASE_URL`
- 可选：`DEEPSEEK_MODEL`

我其实很想做孙宇晨那样的人物，懂得造势，明明才做了1分，却要告诉世人自己做了100分。这为理想主义者，为干实事的人所不齿，但我觉得，这在当今互联网世界，其实是成名或者积累影响力的极佳方式。大众传媒与娱乐不在乎你是否有实力，一个幽默甚至是反面的人设，只要能给大家带来娱乐，就是有价值的。

这个小雅其实没有什么技术含量，只是一个套壳Chatbot，接了一个DeepSeek API，我vibe coding了一个html页面，写了一个心理学方面的Prompt而已。

我当然可以去读个AI研究生，甚至读个AI博士，然后从零开始，一点点地埋头做技术，但是我真的没有这个时间，也没有这个金钱了，我只能去寻求心理学与AI交叉点的机会，努力成为孙宇晨那样的人物——勤奋、机敏、造势。

理想主义，很多年之前我会坚持，很多年之后我也会坚持，但现在不会，也不能。你知道我小时候想做什么吗？我小时候数学非常好，总是考100分，那时的我梦寐以求大学学数学专业，做数学方面的研究。可是到了高中，我的梦想怎么就变成想学商科了？我怎么就开始天天关注商业和市场知识了呢？数学是我年少的爱好，对技术脚踏实地的执着也是我年少的爱好，可这两种爱好在成年人的世界里都是极其奢侈的。

现在我应用心理学本科毕业了，父母鼓励我去读研究生，我说家里哪里有钱读？父母说砸锅卖铁也要供我读。我感到非常痛苦，他们不懂什么学历贬值，也不懂得心理学研究生是多么没有价值，只想着掏空家底为我提供机会。我不读研了，我选择去工作。生活的沉重离我越来越近，技术梦想似乎离我越来越远……

待我入关，自有大儒为我辩经。待我有朝一日财务自由，一定会出钱资助那些不求名、不求利，一心深耕技术的年轻人。你们是年少的我最想成为的人，也是年少的我没有资格成为的人。
