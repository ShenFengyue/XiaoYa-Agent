Psychological Reflection Agent

XiaoYa

一个用于自我觉察的心理学 agent demo，帮助用户温和地识别潜在的创伤痕迹、情绪卡点与防御性行为。

它会帮你做什么

梳理反复出现的人际模式、情绪触发点和内在自我对话。
把回避、讨好、过度理性、控制、麻木等模式视作“保护策略”来理解。
给出一小步可执行的反思问题、记录提示或落地练习。

它不会替代什么

不做医疗诊断，也不替代心理治疗或危机干预。
如果你正处在伤害自己或他人的风险中，请优先联系当地紧急援助或可信任的人。
创伤线索 识别反复被触发的旧经验
防御模式 理解行为背后的保护意义
温和练习 把觉察带回当下和身体

适合怎样开场

最有效的输入通常不是“我怎么了”，而是“我总在什么情境下卡住、躲开、爆炸、麻木或讨好”。越具体，XiaoYa 越能帮你看见模式。

对话工作台

像和一个温和、克制、善于提问的心理学观察者对话。

Streaming Demo

仅用于自我觉察与演示。若你处于即时危险、持续失眠失控、或有明确自伤他伤念头，请优先联系当地紧急援助或身边可信任的人。
